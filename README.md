# Minecraft 聊天栏信息插入工具

一个用于在 Minecraft 多人游戏中实时插入自定义聊天消息的代理工具。

## 主要功能

- 作为代理服务器运行，转发客户端与目标服务器之间的通信
- 支持自定义聊天消息的实时插入
- 支持多个 Minecraft 版本（1.8.x - 1.21.x）
- 支持颜色代码和格式代码
- 实时日志系统，监控连接状态和消息发送
- MOTD 编辑器，支持预览效果
- 服务器地址管理系统

## 技术栈

- Go 语言开发
- 网络通信：`net` 包
- 数据压缩：`compress/zlib`
- 并发控制：goroutines 和 channels
- 数据同步：`sync.Mutex` 和 `sync.RWMutex`
- 日志系统：文件 I/O 和实时监控

## 实现原理

1. 代理服务器
   - 在本地启动 TCP 服务器（默认端口 25566）
   - 作为中间人转发客户端和服务器之间的通信
   - 监听和处理 Minecraft 协议数据包

2. 消息插入机制
   - 构建符合 Minecraft 协议的聊天数据包
   - 根据不同版本使用对应的数据包 ID 和格式
   - 处理数据压缩和解压缩
   - 在适当时机注入自定义消息

3. 版本兼容
   - 支持多个map结构协议版本（47-771）
   - 针对不同版本使用不同的数据包格式
   - 自动检测和适应服务器的压缩设置

## 当前状态

工具目前处于实验阶段，存在以下已知问题：

1. 兼容性问题
   - 部分服务器可能会拒绝连接
   - 某些版本可能会出现消息发送失败
   - 压缩处理可能导致连接断开

2. 常见错误
   - `DecoderException: incorrect header check`：数据包压缩/解压问题
   - 连接意外断开：数据包格式或时序问题
   - 消息发送失败：版本不兼容或服务器限制

3. 稳定性
   - 在某些情况下可能需要多次尝试
   - 长时间运行可能出现内存泄漏
   - 并发处理可能存在竞态条件
